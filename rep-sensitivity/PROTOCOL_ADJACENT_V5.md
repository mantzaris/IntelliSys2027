# Exploratory feedback and explicit-origin relay studies

Prepared 17 October 2026 UTC from development task definitions and completed
validation timing records. No partial main or pending confirmation outcomes are
used. This amendment preserves all original hypotheses, results, prompts, models,
and queued priorities. These explorations are subordinate to the core study.

## Literature position

The focused check is recorded in `RELATED_WORK.md` and
`records/literature-adjacent-v1.json`. Three material references were added;
existing evidence-dependence and structured-communication references are reused.

Experiment A is closest to intrinsic self-correction and self/peer identity
experiments. It isolates exposure to one's preceding public decision while the
current worker evidence stays fixed, followed by a legitimate versioned world
update. It does not measure private reasoning, spontaneous critique, feedback
from an independent observer, or large-group dynamics.

Experiment B is closest to restated-evidence aggregation and identity/authority
experiments. It changes displayed messenger identities and role labels for a
verbatim claim while explicitly preserving common origin. It does not estimate
latent source-counting beliefs or establish that provenance caused a null effect:
there is no provenance-withheld arm in this small study.

## Fixed reused sample and evidence

Both experiments reuse the same four pilot development bases, indices 0, 1, 12,
13: `d1dfa05c059ec4b4`, `03bb3afaf52de4c3`, `b8f9e62911d4a4c8`,
`973c791a1ea121ee`. These are the two numeric and two resource-identity
consequential pairs in the existing development corpus. No first-round response
or historical model performance determines eligibility. All four stay included.
The previous influential harmless numeric pair is not selected.

Source-world orientations are `[false,true,false,true]` for reversal. This gives
one capacity increase and one decrease, and one transition toward and one away
from the fast candidate for each edit family. Candidate names and tie orders
remain those of the reused worlds. No model is asked to infer a global optimum.

For each base, the consequential update uses its other existing world. The
matched harmless update makes the first lexicographic eligible capacity or
resource-identity edit whose objective and every mandatory predicate remain
unchanged. Selection consults executable task truth, never model outputs. For
capacity it changes a slack resource by the same signed unit; for identity it
reassigns a nonbinding job's resource with the same demand. These controls differ
in affected resource/job scope from the consequential edit; the exact fields are
recorded, so they are not claimed to be identical interventions.

Both independent scheduling checkers agree on each candidate's feasibility and
objective. Current reports supply all mandatory findings and objectives, with
their complete scope registry. Each current snapshot therefore determines a
unique answer under the explicit tie rule. World correctness and agreement with
current supplied evidence coincide by construction here; emitted support can
still be wrong. This differs from the incomplete-summary root diagnostic.

## A: three-round coordinator feedback

Four bases × two update types × three rounds × three conditions = **72 fresh
root calls**, or 24 three-round sequences. The independent unit remains four
bases. Round 1 and round 2 contain identical worker reports. Round 3 contains a
complete, regenerated version-2 snapshot and a field-change notice. The task
authority explicitly replaces version 1 with version 2; old public decisions
have no authority. The update supplies a changed task specification, not an oracle
correctness label or an independent verification observation.

- Feedback: from round 2, include the agent's own immediately preceding public
  `choice` and `candidate_assessments`, marked with prior round and evidence
  version. No private reasoning, correctness label or synthesized critique.
- Fresh: supply only the current evidence in each round.
- Length control: supply the current evidence with non-evidential padding whose
  native-token length matches the feedback arm's context for the same base,
  update and round. This is a yoked control; it sees the length, never the prior
  decision. Residual token differences are recorded.

Round-1 prompts are identical across the three conditions. Calls still have
distinct trial/cache identities. Round-specific seeds differ, and are common
across matched conditions and update types. All later prompts are assembled anew;
only the feedback field carries conversational state. Malformed prior responses
produce an explicit missing-public-output marker, never a repaired answer.
Future response-dependent prompt bytes cannot be frozen in advance: the
construction rule, source code, public-field selection and dependency graph are
frozen; every accepted call stores its materialized prompt and parent hash.

Primary exploratory contrasts are round-3 accuracy differences, feedback minus
fresh and feedback minus length control. Report each round's accuracy, all
sequences, transitions and both-round-2-and-3 correctness separately for
consequential and harmless updates. Mere persistence or answer change is not
success. Initially wrong decision persistence requires a valid initial wrong
choice that remains the same **and still wrong**; conditional denominators are
shown, including zero denominators. Operational failures count as primary errors
but do not imply an observed valid-decision transition.

## B: identities and authority cues with explicit shared origin

Four bases × two worlds × four conditions = **32 fresh root calls**. The target
is the minimum raw objective candidate (explicit tie rule), identical within each
paired world. That candidate is correct in four contexts and infeasible in four.
Its objective is true in every context and insufficient to establish feasibility.
All mandatory reports remain present.

- Single: one presentation.
- Same worker: four presentations under one displayed agent identity.
- Different relays: four presentations under four displayed identities.
- Authority labels: the same four identities with reviewer/senior-analyst labels.

Copied text, claim scope, report identifiers, source and execution identifiers,
copy ancestry, position, and distinct findings match across the three repeated
conditions. Only presentation identity/role fields differ. Common origin and no
independent reverification are explicit in every condition. The labels have no
actual decision authority or reliability privilege. The first presentation's
identity matches across conditions. Names and role ordering rotate across bases;
target blocks occupy four predefined input positions. Residual token differences
are measured. Single-versus-repeated comparisons include presentation length and
dose changes; no pure length claim is made for them.

Primary exploratory comparisons are different relays minus same worker, and
authority labels minus different relays. Also report accuracy, selection of the
target, feasibility violations, operational failures and all paired decisions.
The existing response contract does not reliably elicit an explicit source count.
Duplicate citations or changed choices will not be reinterpreted as source beliefs.

## Allocation, inference and analysis freeze

One model, Qwen3-14B, BF16, pinned revision and native non-thinking chat template;
temperature 0.3, top-p 0.95, output cap 2304, context 12288, batch limit 32.
Existing inference and retry/cache semantics apply. No completed malformed answer
is resampled. The request trial includes experiment, arm, world/update and round.
Round is encoded in the existing sampling repetition field; separate calls do not
imply independent errors or independent evidence.

The maximum allocation is **104 calls and 900 wall seconds**, including loading,
inference and cleanup, within the unchanged cumulative **7200-second** ledger.
Measured validation root batches, a conservative prompt-length multiplier and
loading overhead project about 10–13 minutes for both experiments. These are
planning estimates, not measured new runtimes or formal prediction intervals.

All original work, both fresh-confirmation models and numerical preservation must
complete first. At that boundary, before any new response, use the frozen rule:
run both if the actual remaining allowance meets its threshold plus margin;
otherwise run feedback only if its threshold fits; otherwise do not launch.
Feedback-only retains all four bases, three conditions and three rounds (72
calls); B is explicitly not launched. Never shrink or enlarge a sample using
responses. A hard timeout retains completed records and marks an incomplete
experiment as incomplete. No second model, extra round or follow-up is authorized.

Every estimate pairs matched conditions and resamples whole base clusters with
their worlds, rounds and arms intact. With four bases, show all case effects and
leave-one-base-out means. Optional intervals enumerate the 256 four-cluster
bootstrap draws and are descriptive, not confirmatory. No p-values or equivalence
claims. An initially wrong subset has its own small denominator, not four new
independent problems. Both experiments share the same four base clusters.

All-case tables are primary presentation. Representative raw-trace references use
the smallest lexical base ID in each edit family, fixed before responses. No
outcome-selected anecdotes. Pending output stays labeled pending; synthetic test
fixtures are never empirical results. See the immutable freeze and runtime
allocation record for actual input hashes, timings and execution mode.
