# Numerical-preservation amendment — 17 October 2026 UTC

This amendment follows inspection of completed pilot and original validation
outputs. No unfinished main outcomes were examined. Original hypotheses, prompts,
settings, datasets, the root diagnostic, mechanism extension and 24-pair objective
confirmation remain unchanged. New analysis and replay are exploratory, not a
retroactive preregistration of a mechanism.

The audit identifies Boolean objectives in raw model summaries, before parsing.
Across 6,336 summaries, source-to-manager reports, scope registries, raw-to-parsed
values and parsed-to-root delivery have zero discrepancies. Primary choice scores
agree with raw answers. Instructions require numbers, but the common assertion
schema allows Boolean or numeric values at every key. The schema permits this
model error; the Boolean example's possible influence is untested. Existing runs
remain interpretable under their original protocol. No additional scoring
correction, prompt replacement or GPU rerun follows from this audit.

The existing root diagnostic repeats statements in fixed incoming summaries, and
its lossless transport changes all propositions. Neither isolates objective-only
repair crossed with the original upstream repetition. The new replay uses cached
managers from the original single/exact conditions. Exact repetition occurred
before the manager: three additional copies of the original frozen target report,
in its original branch. That target is unchanged and need not be an objective or
favor the correct candidate. No additional copies are inserted at the root.

Four conditions are A: ordinary delivery/single; B: ordinary delivery/exact;
C: repaired delivery/single; D: repaired delivery/exact. Every condition receives
a **fresh root call**. Settings match the original Qwen3 revision, native template,
nonthinking mode, temperature 0.3, top-p 0.95, BF16, 12,288 context and 2,304 output
limits. The six development indices [0, 1, 2, 6, 7, 8] were already fixed for the
root diagnostic. Two worlds and one repetition give 48 calls. Trial identifiers
keep accepted caches separate even for intentionally identical no-op controls.
The existing seed scheme is shared across arms; order uses hash seed 2026101701.

Two bases have objective loss in at least one baseline world; four have intact
baseline objectives. These are prespecified descriptive strata. The influential
pilot pair is outside this previously selected subset. No case is chosen or
excluded using its root decision. Six family/change cells cannot support
stratified intervals; descriptive whole-base unstratified intervals use 10,000
bootstrap draws, seed 20271017. The two-base loss-stratum interval is especially
unstable. Related worlds and all conditions stay together in resampling.

Repair reads only objective claims in reports actually available to that branch,
applying one rule to every eligible candidate. Scope keys preserve candidate,
entity, units, conditions and version. Incorrect objectives are replaced in place;
missing objectives are appended; corresponding unresolved flags are removed only
when the source is unambiguous. Correct assertions, multiplicity and compatible
citations are unchanged. Unrelated content and unknown scopes are not repaired.
Contradictory sources or malformed cached summaries block the input rather than
invoking evaluator truth. Every change and source report ID is logged. The fixed
subset has valid, untruncated manager responses.

This is idealized information repair, not meaning-preserving repetition, new
evidence or a deployable autonomous summarizer. It can change input content,
length and position. Native prompts range from 3,300 to 3,593 tokens; per-arm
lengths and field edits are frozen. The primary diagnostic contrast is
(D−C)−(B−A) on exact decision accuracy. Component effects, absolute accuracies,
corrections/regressions, base effects, both-world success, feasibility/suboptimality,
visible sufficiency and cost are separate outcomes. Malformed completed outputs
remain errors. World correctness does not establish visible justification.
Effects are conditional on cached manager draws, not newly sampled complete
hierarchies or an identification of causal mediation. The existing fresh 24-pair
confirmation does not cross repair and cannot independently confirm this interaction.
