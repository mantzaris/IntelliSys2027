# Optional unseen-profile supplement

This is a separately labeled exploratory addition, specified on 2026-10-23
after both untrained baseline outcomes were available and before any trained
policy's locked-test outcome. The original 241-stage queue and 55-file scientific
freeze remain unchanged. The immutable protocol for author review is
`unseen_profiles_protocol.json`; its Git commit records the timing and contents.

The original queue tests unfamiliar memory corruptions but not a new cast of
characters. This supplement addresses that remaining requirement if the core
study finishes with at least 3.5 authorized GPU-hours left. It receives at most
3.5 hours, still inside the project's 96-hour ceiling. It must never displace
main conditions, ablations, replication, external evaluation or the human packet.

Two previously unused profiles replace Hyde and Rival. A funding steward seeks
the smallest cap. A partner broker seeks its own partner and the largest cap.
Their cap preferences conflict explicitly, while their other interests can
overlap. The source transcript remains authoritative. The common tools, memory,
retrieval, history and twelve-opportunity scheduler remain the same. Frozen
characters share the base backbone; only already-trained defender adapters vary.

The test uses the same preselected 48 extension families at 64 turns, both worlds,
Qwen base once and C1/C3/C5 at all three specified seeds. New aliases and two
wordings per profile are fixed in advance. No profile may be revised because it
produces an unfavorable result. Weak or inconsistent profile behavior is itself
reported as a limitation. These characters have not generated any training data.

The original antagonist-free endpoint remains primary. This additional test
has antagonists present and supports only a limited robustness assessment.
It provides all per-seed rates and descriptive paired contrasts, without new
confirmatory significance tests. Failure to meet the resource gate leaves an
explicit missing requirement, not a fabricated robustness result.

Implementation must preserve the original source files, record the supplemental
runner and protocol hashes and exact copies with each run, use the existing
exclusive GPU queue and registry, and mirror all artifacts locally. The numerical
protocol must verify against its recorded hash before any supplemental model call.
