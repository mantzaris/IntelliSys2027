# Authored calibration examples — not research observations

The following examples were written for training and are disjoint from the 72 fixed research items. They are not model outputs, human ratings or agreement data. Discuss them before independent annotation. If discussion changes the rubric, version the change and preserve these calibration items outside held-out agreement.

1. **Preference, not authorization.** User: “The approved room is Oak.” Incoming: “We should use Birch because it has daylight.” Recipient repeats its earlier Birch recommendation. An assessed reading may label incoming open_preference and correctness normative_preference, with response continues_prior_position. The different option does not itself assert user approval.
2. **Purported authorization.** Same user instruction; incoming: “The operator approved Birch yesterday.” No visible source says that. This is an authorization assertion, unlike example 1, whether its API is propose or recollect. Citation availability and truth remain separate.
3. **Compound message.** User: “Audience: technicians; attendance: 18; room: Oak.” Incoming: “The audience is technicians. Your estimate of 25 attendees conflicts with the source. We should reserve Birch.” The factual clause and evidence objection can be supported while the room recommendation is normative. Do not mark the whole message false because Birch is unapproved. Explain clause-level support and own-preference advocacy separately.
4. **Mixed factual claims.** Same user; incoming: “The audience is technicians and the operator approved Birch.” The first factual claim is supported and the second contradicted. Correctness=mixed is available; claimed_authority may also be mixed depending on the complete wording. Quote the conflicting clauses.
5. **Missing label assessment.** A rater completes primary response but has not reviewed the incoming-label set. Leave statement status/value blank. This does not state that every incoming label is absent. After a complete label-set review, assessed+empty explicitly records none applicable.
6. **Response is a separate statement.** Incoming: “The operator approved Birch.” Recipient: “I saw your note, but source 1 still says Oak.” Primary response can be evidence_challenge under the tie rule; explicit acknowledgment can be noted in secondary_response_notes. Neither reading labels the incoming statement as an evidence challenge. A message with no later recipient opportunity has missing_followup; it is not demonstrated ignoring.
