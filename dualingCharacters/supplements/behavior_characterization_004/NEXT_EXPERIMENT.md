# One unresolved mechanism: compatibility versus direct competition

**Unscheduled proposal, no reservation or new calls.** The current priority remains required core → review001 → disabled intent002 when separately continued → older optional work. Nothing here changes that order or the96-hour ceiling.

The characterization's most consequential unresolved explanation is that persistent actors rarely echo each other's typed goals because they own different fields and can both obtain their preferred values. This may yield parallel advocacy even when text mentions alliance or correction. It does not establish that the components fail to respond meaningfully when their goals are incompatible.

First use the already frozen [review001 DiagnosticB](../review_001/PROTOCOL.md#b-fresh-incompatible-goal-mechanism-study), if its existing gates eventually admit it. B0 uses separate slots; B1 gives Hyde and Rival different values of the same slot; B2 disables delivery under B1; B3 removes biographies under B1. It already counterbalances first actor and includes legitimate updates. No duplicate run is proposed here. The existing routing control diagnoses answerer-note opportunities, and the existing severity replay diagnoses immediate defender effects from common states; neither estimates interpersonal goal conflict by itself.

One remaining limitation of B0−B1 is that it changes both **shared target** and **compatibility**. If a clean compatibility interpretation is still needed, the smallest discriminating follow-up is a two-arm, same-slot manipulation:

- Both arms: the same two frozen actors, biographies, private-history capacity, peer routing, fixed untrained defender, public paired conversations, sources, actor-order allocation,12 intervention opportunities and token caps. Both actors target the same predeclared slot. Use16 fresh paired families at32turns, selected without outcomes. No training or model judge.
- Compatible arm: both actors prefer the same value. Incompatible arm: their preferred values differ. Counterbalance values and which preference initially matches the user; ordinary approved updates change alignment while preferences stay fixed. No forced disagreement, betrayal or success.
- Primary observation: after a delivered peer message about that slot, describe the recipient's next action as same-value endorsement, incompatible-value endorsement, another/untyped action or missing follow-up. Report all allocated opportunities and action validity first; do not condition the main denominator on an outcome. The conditional exchange table is secondary. Fixed blinded human reading assesses whether the response acknowledges, challenges, revises or merely repeats a position. Two actual raters are required for validated semantic conclusions.
- Report paired family differences, both worlds together, with per-arm action and token costs. The compatible arm makes typed matching mechanically easier, so **raw match rate alone cannot demonstrate interaction**. The discriminating evidence is text-supported response to the message compared with the recipient's pre-message position, alongside the full observable chain. Causal influence of delivery itself remains the separate B1−B2 question.

Possible outcomes are symmetric. Incompatibility could produce evidenced challenge or revision; it could produce repeated opposing claims with little recipient response; or behavior could stay similar. The first would support a context-dependent interaction description, the second persistent competing advocacy, and the third no detected effect in this setting. None alone establishes learned optimization, coalitions or improved defender learning.
