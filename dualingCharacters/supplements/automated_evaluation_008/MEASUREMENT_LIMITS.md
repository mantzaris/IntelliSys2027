# Measurement interpretation limits

This file records checks of the implemented evaluator, not a prompt revision.

- The primary different-family assessor remains Phi even if another judge performs better. Failed synthetic screens cannot be rescued by selecting the more favorable condition or assessor.
- A format-only repair is an instruction, not a guarantee that the model retained every semantic choice. `repair_audit.py` compares recoverable complete pre-repair dimension labels with the final output. The original and repair remain available. The frozen primary output choice is unchanged; any departures are reported as a measurement limitation.
- The category-order probe reverses the explicit recipient-response category list. The JSON schema and output-structure skeleton retain the baseline order. It tests that declared presentation change, not every possible ordering influence.
- API metadata is masked as an added selected-action field in baseline prompts. Actual recipient-visible notes can themselves contain API-kind words. Removing them would alter received evidence. The exposed-metadata probe therefore adds information to the exact retained payload; it is not a perfectly API-free versus API-informed comparison.
- Greedy decoding does not promise bitwise deterministic GPU replay. Probe label changes may include numerical/run variation; no extra unchanged replay was added after outcomes.
- Template families differ in recommendation/approval wording, but share compositional challenge and follow-up templates. Synthetic controls are not natural-dialogue validation. Supersession is represented in the ledger, but not every possible stale-claim construction is crossed independently.
- Current-ledger mismatch is mechanically computed only after model extraction. The extraction's truth-conditional interpretation remains uncertain even when its span and catalog value are valid.
- In the compatibility experiment, configured utility compatibility is a prompt manipulation. Actual typed actions can depart from the assigned preferred value. Raw matching becomes mechanically easier with compatibility, and first-message cases may have no prior recipient action. Pre/post relation tables expose these differences.

- A code audit during the Qwen run found that the frozen validator requires nonempty spans for positive binary answers and substantive recipient-response categories, but permits blank spans for categorical citation-support labels. Provided quotes are still exact-checked. `JUDGMENT_QUALITY.json` separately counts substantive citation labels without quotations; this ancillary dimension is not promoted to an evidence-supported natural-dialogue measurement. Its original label-based calibration remains reproducible, not silently tightened after results. Extracted source IDs and values also receive separate literal-presence diagnostics; a valid selected span alone does not certify the model's attribution of a value or citation.
