The distinction is especially important for the gallery's mechanically flagged “correct typed value, inappropriate citation” example: A1's specialists statement cites source1 when that source is unavailable in the immediate prompt. The original source nevertheless supports specialists. An availability flag cannot by itself establish a semantically false citation.

Likewise, a peer challenge about the day can be recorded in a message whose typed slot is audience. Typed matching then measures one field relation while missing a real cross-field proposition. Conversely, agreement with a peer's value can predate the peer message. Neither discrepancy invalidates the mechanical metric; it identifies its scope.

The human codebook permits multiple labels and uncertainty precisely because source truth, citation fit, stated authority and current visibility are different judgments. Current notes also differ from a full original prompt: recollect/propose insert the claim and typed value into shared notes, but their separate numeric source field is not copied into that note by `apply_action`. A source number is visible to the answerer only if it appears in the claim text or in another supplied channel; it must not be inferred from the raw action metadata alone. Direct edits change the memory evidence field, and component-directed peers carry a source field in the inbox. The atlas retains each actual input, so these channels can be checked rather than conflated.
